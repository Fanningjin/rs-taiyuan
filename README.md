# rs-taiyuan ｜ 太原汾河沿线 Sentinel-2 多时相遥感与土地覆盖分类

用 Sentinel-2 L2A 两期影像，在太原城区北部·汾河沿线 10×10 km 研究区完成一套完整的遥感处理流程：
**批量预处理（AOI 裁剪 + SCL 云掩膜）→ 两期 NDVI 对比 → 五指数特征工程 → 六类样本采样（70/30 分层）
→ 9 波段特征栈随机森林六类分类（验证集 OA 0.959 / Kappa 0.950）→ 4 月影像跨期迁移与域漂移诊断**。

## 数据

| 项 | 说明 |
|---|---|
| 数据源 | Copernicus Data Space（Sentinel-2 L2A，含 SCL 场景分类层） |
| 图幅 | `T49SFC`（UTM 49N，EPSG:32649） |
| 第一期 | `S2A_MSIL2A_20250414`（春季，裸土/裸耕为主） |
| 第二期 | `S2C_MSIL2A_20250906`（初秋，植被季） |
| 研究区 | 太原城区北部·汾河沿线 10×10 km（`aoi.json`：625000 / 4194000 / 635000 / 4204000，面积 100 km²） |

> 2026-11-13 研究区调整：初选的北郊旱作河谷窗口 SCL 水体占比 0.00%（六类中水体几乎无样本），
> 在同一景内改选汾河城区窗口——覆盖汾河、主城区、西山林地与北部农田，六类齐全；
> 两期 SCL 坏像元 0.0192% / 0.1328%，无重新下载数据。

## 环境

Miniforge3 + conda 环境 `rs`（Python 3.11），主要依赖：`rasterio`、`numpy`、`pandas`、`matplotlib`、`scikit-learn`（含 joblib）；
样本核订使用 QGIS 3.44（conda-forge 安装于 `qgis` 环境）。

## 处理流程（均在项目根目录运行）

```bash
# 1) 批量预处理：裁剪 + 云掩膜（输出 {scene}_B04_clean.tif）
python batch_preprocess.py --input data/raw --aoi aoi.json --out data/processed

# 2) 两期 NDVI（输出 {scene}_NDVI.tif）
python src/d06_ndvi.py

# 3) 两期对比 + 差值图
python src/d07_diff.py

# 4) 五指数特征栈（输出 features_20250906.tif）
python src/d08_features.py

# 5) 真彩色底图 + 弱监督候选采样点
python src/d09_truecolor.py
python src/d09_sample.py

# 6) 少数类补点（可选）
python src/d09_extra.py

# 7) 70/30 分层划分（读 data/samples/samples_cleaned*.csv → train/val）
python src/d09_split.py

# 8) D10：特征栈 → 采值 → 训练 → 评估 → 全图预测 → 制图
python src/d10_stack.py
python src/d10_extract.py
python src/d10_train.py
python src/d10_eval.py
python src/d10_predict.py
python src/d10_map.py

# 9) D11：4 月特征栈 → 9 月模型迁移预测 → 两期对比制图
python src/d11_stack_apr.py
python src/d11_predict.py
python src/d11_map.py
```

## 特征栈 `features_20250906.tif`

5 波段、float32、10 m 网格、EPSG:32649、nodata = NaN。
波段顺序如下（与 `src/d08_features.py` 中字典顺序一致）：

| 波段 | 指数 | 公式 | 说明 |
|---|---|---|---|
| 1 | NDVI | (B08 − B04) / (B08 + B04) | 植被指数 |
| 2 | NDWI | (B03 − B08) / (B03 + B08) | 水体指数，McFeeters 1996 |
| 3 | MNDWI | (B03 − B11) / (B03 + B11) | 水体增强指数，Xu 2006；B11 由 20 m 双线性重采样到 10 m |
| 4 | NDBI | (B11 − B08) / (B11 + B08) | 建成区指数 |
| 5 | BSI | ((B11 + B04) − (B08 + B02)) / ((B11 + B04) + (B08 + B02)) | 裸土指数 |

## 采样与训练/验证划分

- 类别体系（6 类）：耕地 / 林地 / 草地 / 水体 / 建设用地 / 裸地及其他。
- 弱监督采样流程：指数阈值初标（NDVI 分层 + MNDWI / NDBI / BSI，互斥规则按优先级）
  → 每类随机抽样 120 个候选 → QGIS 真彩色目视核订删除误判像元。
- 少数类补点：水体/林地/草地用更严阈值补抽；耕地加"田芯匀质性 + 北部农田带"空间先验；
  裸地因屋顶光谱污染改用已知裸地点邻域扩散 + 人工补点。
- 样本量 646：水体 131 / 林地 131 / 耕地 115 / 建设用地 100 / 草地 95 / 裸地及其他 74。
- 70/30 分层抽样（每类内部）：训练 452 / 验证 194（验证比例 0.300，各类 0.297–0.305）。

## 随机森林分类（D10）

### 9 波段特征栈 `features9_20250906.tif`

在 5 指数基础上加入 4 个原始波段（B02 / B03 / B04 / B08），共 9 波段、float32、10 m 网格、nodata = NaN。
波段顺序：`B02_blue, B03_green, B04_red, B08_nir, NDVI, NDWI, MNDWI, NDBI, BSI`
（动机：指数为比值运算，丢失绝对亮度；裸地/屋顶等易混地物依赖原始反射率差异来区分。）

### 模型与验证精度

- 特征矩阵：训练 452 × 9 / 验证 194 × 9（按 `x_utm/y_utm` 经仿射逆变换取像元值）。
- `RandomForestClassifier(n_estimators=300, class_weight="balanced", random_state=42)`，
  训练耗时 1.2 s；训练集精度 1.000（树模型自背，不作为泛化依据），**OOB 精度 0.914**。
- **验证集：OA = 0.959，Kappa = 0.950**（194 样本，仅用作最终一次评估）。
- 类别表现：水体 39/39、裸地 22/22 全对；错误集中在植被连续统（耕地↔草地↔林地互串）；
  草地 precision 0.903 最低（宽泛类，吸收其他类误判）。
- 特征重要性前五均为指数：NDVI .194 / NDWI .185 / MNDWI .156 / BSI .139 / NDBI .127。

### 全图分类结果

- 998,672 个有效像元（NaN 1,328 个跳过），预测耗时约 4 s；
  分类图 `data/processed/classified_20250906.tif`（uint8，nodata = 0，
  编码：1 裸地 / 2 建设 / 3 耕地 / 4 林地 / 5 草地 / 6 水体）。
- 面积占比：草地 38.46% / 耕地 22.86% / 裸地 14.55% / 建设 14.24% / 林地 7.92% / 水体 1.97%
  （水体占比与 SCL 统计 1.8% 吻合，编码映射经交叉验证无倒挂）。
- 图件 `outputs/d10_classified_map.png`：RGB 底图与分类图对照 + 图例。

### 局限与改进方向（全图目视体检结论）

| 问题 | 归因 | 改进方向 |
|---|---|---|
| 西山整片山林被分为草地/耕地，林地仅占 7.92% | 森林样本多来自公园/河岸林带；山区灌木林、稀树灌草未覆盖，植被连续统光谱重叠 | 补西山林地/灌草样本；引入纹理或时序特征 |
| 草地 38.46% 一家独大，城中村房顶进草 | 草地是物理上最宽泛的类（兜底类）；城区屋顶样本不足 | 增补屋顶负样本（归建设）；评估类体系拆分/合并 |
| 北部部分收割耕地判为裸地 | 单期（9 月）影像下收割耕地与真裸地光谱几乎一致 | 引入时序特征（2025-04-14 影像）区分常裸与季相裸 |
| 城区零星水体杂点 | 蓝屋顶误判（D9 弱监督阶段已知问题） | 后处理最小斑块/众数滤波；蓝屋顶样本归建设 |
| 山地道路未分出 | 道路像元占比极小、无道路类 | 可接受漏判；如需可单列道路专题 |

> 验证集 OA 0.959 与全图观感存在落差：验证样本与训练样本出自同一采样流程、空间近邻，
> 存在空间自相关导致的"近邻泄题"；小样本弱监督条件下，全图目视质检仍是必要环节。

## 4 月分类迁移与域漂移诊断（D11）

用 D10 的随机森林（`models/rf_20250906.joblib`）直接预测 2025-04-14 影像：
`features9_20250414.tif` 与 9 月栈采用完全相同的 9 波段定义与顺序（预测前有 assert 校验），
即 **train on September, predict on April** 的跨期应用（`d11_stack_apr.py` → `d11_predict.py`）。

### 两期类别占比对照

| 类别 | 9 月（本季训练） | 4 月（迁移预测） | Δ (pp) |
|---|---|---|---|
| 裸地 bare | 14.55% | 26.69% | +12.1 |
| 建设用地 builtup | 14.24% | 50.27% | **+36.0** |
| 耕地 cropland | 22.86% | 0.41% | **−22.5** |
| 林地 forest | 7.92% | 0.05% | −7.9 |
| 草地 grassland | 38.46% | 20.53% | −17.9 |
| 水体 water | 1.97% | 2.05% | +0.1 |

（4 月全图有效像元 999,808，NaN 192 跳过。）

### 诊断：域漂移（domain shift）

四月耕地刚翻耕，地表干硬发亮，光谱与水泥屋顶高度相似，被大量误分为建设用地；
落叶期林地与返青前的草地露出裸土，也被大比例误分为建设用地或裸地，导致建成区、裸地虚增，
耕地、林地虚减。城市规模不可能五个月内扩大三倍以上，这一巨变首先被常识否掉。
水体占比两期仅差 0.1 个百分点，说明指数体系和模型判别逻辑本身没有出错——本质是**域漂移**：
模型只在 9 月的物候状态下学习过各类地物的光谱特征，4 月同一地物的光谱已随季节改变，
跨季直接应用必然失效。

目视证据（`d11_map_two_seasons.png`）：4 月分类红色最集中的北部大田，在 RGB 上对应
规则矩形翻耕田块（城市扩张不会按田埂长）；西山与河岸的成片绿色在 4 月几乎消失；
汾河与坑塘蓝带两期位置、形状完全重合；城市核心区红色网格两期一致（正控——真实建成区
迁移判断正确，失效的只是季节敏感表面）。

**对下游的含义**：两期分类叠加出的"耕地 → 建设用地"大面积转移属伪变化，不能作为变化检测
结论直接上报；后续以 NDVI 差值为主要交叉证据（D13），叠加仅用于可信转移类型与稳定类核对。

### 工程教训（本次踩坑）

- **换 AOI 是全局事件**：`data/processed/S2_20250414_B02/B03/B08_aoi.tif` 是旧 AOI（阳曲）的
  产物，换窗后主链重跑但 d04 裁图未重跑，曾导致 4 月 RGB 图红通道（新窗 B04_clean）与绿蓝
  通道（旧窗）来自两个窗口、颜色异常。修复：RGB 合成改为从 SAFE 现读（`read_safe_10m`）。
- **跨文件拼图必须核对坐标**：Tiepoint 646900/4247120（旧）≠ 625000/4204000（当前），一行
  metadata 检查即可暴露问题。
